Dividend Portfolio

プライバシーポリシー

最終更新日: 2026年11月11日

このポリシーは、Dividend Portfolio（以下「本アプリ」）における情報の取り扱いを説明します。本アプリは、個人の配当ポートフォリオを管理し、株価更新、企業分析、候補銘柄の検討を支援します。

取り扱う情報

本アプリは、利用者が入力・管理する次の情報を機能提供のために取り扱います。

  • 保有銘柄、配当、株価更新に関する情報
  • 企業分析の依頼・結果、候補銘柄に関する記録
  • Google Sheets とデータを受け渡すために必要な情報
  • Google Sheets への接続に必要な認証情報

公開されているこの情報ページ自体は、ポートフォリオ情報を表示しません。

情報の利用目的と処理先

本アプリの保存と処理
保有状況、配当、株価、企業分析、候補銘柄に関するデータは、アプリ機能を提供するため Cloudflare Worker と D1 で処理・保存します。
Google Sheets との連携
Google Sheets はアプリと情報を受け渡すために使用します。PRICE_FEED、AI_TASK_QUEUE、AI_RESULT、および候補銘柄用のキューを通じて、株価データや分析に関する情報を連携します。アプリはサーバー設定で指定されたスプレッドシートを使用します。
株価情報の取得
株価更新を行う Google Apps Script は、外部の株価データ提供元に通信して価格情報を取得します。この通信は Apps Script の外部リクエスト権限に基づきます。
ChatGPT を使った分析
ChatGPT 分析は利用者が Sheets を介して明示的に開始する任意の操作です。利用者が AI_TASK_QUEUE の分析依頼を ChatGPT に渡し、結果を AI_RESULT に戻す場合があります。本アプリが ChatGPT を自動で呼び出したり、分析内容を自動送信したりすることはありません。利用者が ChatGPT に渡した情報は、ChatGPT のサービス提供者によって処理されます。

Google アカウントへのアクセス

Google OAuth で使用するスプレッドシート権限は、Google アカウント内のスプレッドシート全般を読み書きできる広い権限です。本アプリはこの権限を、設定済みのスプレッドシートに対する本アプリの機能提供に使用します。

Google API Services から受け取った情報は、利用者に見える本アプリの機能を提供・改善する目的でのみ利用します。本アプリは Google API Services User Data Policy の Limited Use 要件を含む規定に従って情報を取り扱います。Google API Services User Data Policy をご確認ください。

第三者サービスと情報の共有

本アプリの運用には Cloudflare と Google のサービスを使用し、上記の目的で情報を処理します。株価更新では外部の価格データ提供元から情報を取得します。利用者が ChatGPT に分析依頼を渡す場合、その内容は ChatGPT のサービス提供者にも送られます。

情報を販売したり、広告目的で利用したりしません。利用者が開始していない ChatGPT への自動送信は行いません。

認証情報の保護

Google 接続に必要なトークンなどの認証情報は、サーバー側の保護された秘密情報として管理します。公開ページやブラウザー画面に秘密情報を掲載しません。

データの管理、接続解除、削除依頼

  • Google Sheets 内の情報は、利用者が自分の Google アカウントから確認、編集、削除できます。
  • Google との接続権限は、Google アカウントの「サードパーティとの接続」から取り消せます。
  • Google の接続権限を取り消しても、すでに Google Sheets や本アプリ内に保存された情報は自動では削除されません。
  • 本アプリ内に保存された記録の削除を希望する場合は、下記の窓口から依頼してください。

お問い合わせと削除依頼は GitHub Issues で受け付けます。この窓口の投稿は公開されるため、保有銘柄、金額、認証情報などの個人情報や秘密情報を書き込まないでください。

お問い合わせ

本ポリシーや情報の取り扱いについては、GitHub Issues からお問い合わせください。公開窓口には個人情報や秘密情報を記載しないでください。

本ポリシーを変更する場合は、このページに改定内容と更新日を掲載します。
